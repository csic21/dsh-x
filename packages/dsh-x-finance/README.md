# dsh-x-finance

为 DeepSeek Harness 提供只读报价工具 `dsh_x_finance_quote`，以及 A 股自选（含名称搜索）、市场全景（含沪深300基金规模占比下钻）、**全球指数**、黄金面板、日 K 图表工作台、**量化分析**、**自选研究信号**、**全市场日线量化**、**尾盘放量下跌扫描（上午盘 / 下午盘）**、**热点题材筛选**与**涨停接力概率**。不包含交易、下单、账户或持仓接口，也不提供投资建议，也不抓取新闻或做事件归因。

> 本包原名 `dsh-x-stock`。改名时保留了三处兼容：profile 目录 `.dsh-x-stock` 会被一次性改名为 `.dsh-x-finance`，旧 localStorage 键只作为只读回退，旧环境变量 `DSH_X_STOCK_*` 仍等价于新的 `DSH_X_FINANCE_*`。

## 配置与使用

通过包内 `dsh.bundle.patch` 和 `cordis.patch.yml` 注册 Cordis 插件；需要宿主提供 `@deepseek-ai/cordis`、`@deepseek-ai/dsh-tools`。本实现按官方内核 `v0.2.1-rc.3` 的 `defineTool` 接口编写，运行时 Node.js 22 或更新版本。

在启动宿主的环境中设置 `FINNHUB_API_KEY`。请通过自己的密钥管理方式设置，不要向模型发送密钥、放进工具参数、提交到仓库或写入打包产物。插件不会创建账户、保存密钥或购买订阅。没有密钥时直接返回配置提示，不发请求。

例如要求模型：“查询 AAPL 报价并告诉我报价时间。”工具参数：`{"symbol":"AAPL"}`。一次只接受一个明确的 Finnhub 代码，自动去除首尾空白并转为大写；允许字母、数字、点和连字符，最多 32 个字符。代码语法有效不代表供应商支持该证券。遇到歧义应先向用户确认。

## 数据来源与边界

- 使用 Finnhub 官方 `GET https://finnhub.io/api/v1/quote`，代码放在 `symbol` 查询参数，密钥放在 `X-Finnhub-Token` 请求头。
- 官方文档：https://finnhub.io/docs/api/quote
- 官方 SDK 的鉴权与字段说明：https://github.com/Finnhub-Stock-API/finnhub-go 和 https://github.com/Finnhub-Stock-API/finnhub-go/blob/master/docs/Quote.md
- 返回价格、开盘/最高/最低/前收盘、涨跌额和涨跌百分比，以及供应商、抓取时间和可用的报价时间。缺失的可选数据为 `null`，不会自动补成零。
- `quotedAt` 来自响应中的 Unix 秒时间 `t`；缺失则为 `null`。`fetchedAt` 只是抓取时间，不能当作行情时间。百分比保留供应商的百分数，不额外乘以 100。
- 接口不提供币种，因此插件不推断或输出币种。报价可能延迟、停留在前一个交易时段，市场覆盖和许可取决于供应商及账户订阅；不能保证实时、A 股/港股覆盖或所有代码可用。
- `dsh_x_finance_quote` 自身不使用未验证的免密接口或网页抓取作为兜底。它没有做带真实密钥的在线验证；离线测试全部使用模拟响应，示例数字不是实时行情。A 股界面另有显式开启的本机免密钥适配器，见下文。

## 安全与可靠性

固定 HTTPS 主机，拒绝重定向；默认整个请求含响应体最多 10 秒，响应体最多 16 KiB；尊重宿主取消信号，不自动重试限流请求。校验 JSON、价格、可选数值和时间。上游错误正文及原始网络错误不会回传，避免泄露密钥。成功结果会明确包含数据限制提醒。

插件不改变宿主的工具审批策略。外部返回内容仅作为行情数据校验，不执行其中任何指令。

## A 股自选界面（新增）

界面与原有 Finnhub 工具相互独立。侧栏新增「股票」入口，通过官方 `main` keyed slot 打开独立股票详情页；底部条点击股票先选择该股，再用 `ctx.layout.selectPanel('dsh-x-finance')` 导航，不改当前 Session，也不向对话插入消息。「返回对话」调用 `selectPanel(null)`。

- **自选是自选，固定是固定。** 自选清单只在这个页面显示、可以滚动了，加入自选不会让任何股票出现在底部；只有显式点「固定」的股票才进入底栏，最多 8 只（`MAX_FIXED`）。自选本身只受 200 条的存储安全上限约束，不按涨跌重排，保持用户手动顺序。取消固定不会移除自选。
- 可以手动选择上海、深圳或北京交易所并填写六位代码（内部标识如 `SH.600519`、`SZ.000001`、`BJ.430047`），也可以在搜索框输入名称片段、拼音首字母或代码，从目录结果中选择后自动回填交易所与代码。不把同代码的不同交易所合并，不猜上市市场。
- 底栏单行横向滚动，不跑马灯；显示名称或代码、价格、带正负号的涨跌幅；收起后保留固定数量及恢复按钮。一条都没固定时底栏完全不注册 `shell.bottom`，把插槽让给其他插件。macOS 上 `⌥⇧S`（Option+Shift+S）、Windows 与 Linux 上 `Alt+Shift+S` 可以随时隐藏/显示整个底栏（同一组键，输入框内不劫持按键；Mac 上按物理键识别，不看被 Option 改写后的字符），隐藏状态写入同一份本地记录，页面里有恢复按钮。股票详情页始终是独立入口。
- **设置面板与老板键**：页面右上角「设置」集中管理低调模式、底部固定栏、免费源开关与快捷键。低调模式用 `⌥⇧B`（Windows / Linux 为 `Alt+Shift+B`）一键切换：涨跌色与强调色降为接近中性的低饱和色调，标题与页签改为「工作台 / 列表 / 概览 / 关注 / 指数 / 商品」，并默认隐藏底部固定栏；打开「低调模式下保留底栏」（或点自选栏底部的「低调模式下显示固定栏」，或按一次底栏快捷键）后，底栏不再让位，而是换成同一套中性配色继续显示。再按一次恢复。热力图与 K 线保留细微的方向差异，不改变任何请求、自选或行情数据。设置只保存在当前浏览器的 `dsh-x-finance:settings:v1`（`{version:1,discreet,barInDiscreet}`），旧载荷按未保留底栏处理。
- `localStorage` 只保存版本、代码/别名、顺序、固定状态、收起与隐藏状态；不保存行情、密钥、账户、持仓或生成的分析。载荷为 `version: 2`（`items[].fixed`、`barHidden`）；旧 `version: 1`（`pins`，自选即底栏）与其旧 scope key 会被一次性导入为「全部未固定」，不改写原记录。同浏览器、同站点、同宿主 profile 可恢复，标签页通过 storage 事件同步；不跨设备或浏览器同步。宿主在官方 `profileContext.dir` 下持久化普通随机 scope 标识，通过受保护的精确 route 交给客户端。客户端确认 scope 后才读取对应 localStorage key；不同 home/profile 隔离，同 profile 重启稳定。未分区 key 不读取。切换/重连期间清空旧视图并停止存储事件读取，获取 scope 失败时暂停管理，可重试。scope 不是凭据，不包含目录路径或凭据哈希。存储拒绝时保留当前内存操作并展示提示。
- 详情页提供报价/来源/报价时间/获取时间，走势与成交、基本面和分析区块。没有数据时明确留空，不绘制假 K 线、不编财务指标、不生成没有依据的判断。

### 名称搜索（含 ETF）

- **查询即看，不必先加自选**：页面顶部（所有页签都可见，包括临时查看页）有一个独立的「查询股票」框，与添加表单共用同一份目录。输入名称、拼音首字母或代码选中后，直接打开该股的详情、日 K 与分时，属于**临时查看**：不写入自选、不改动当前选中行，需要保存时再点详情页的「加入自选」。添加表单里的搜索仍然只负责回填交易所与代码，两个入口互不影响。
- 搜索框按名称片段（如「比亚」→ 比亚迪）、拼音首字母（`byd`）或代码（`002594`、`510300`）查询；结果限制为可交易的 A 股、ETF、QDII-ETF、LOF、QDII-LOF 与 REIT，最多 10 条。指数、港美股、场外基金（`jj`）与权证被过滤，不进入自选。选中结果后自动填入交易所和六位代码，并在别名为空时预填目录名称，仍可直接手填或修改。
- 目录来自腾讯公开接口 `https://smartbox.gtimg.cn/s3/`（来源名 `smartbox.gtimg.cn (unofficial)`）。它和市场全景、自选详情、固定栏报价共用同一个默认关闭的「本机免费源」开关：只有页面开关（或 `marketSource` 配置）开启后才会请求；关闭时搜索框只显示开启入口，不发送任何请求。
- 搜索仅由用户显式输入触发。关键词经 Host 通过固定 HTTPS 主机发出，拒绝重定向，8 秒超时，响应上限 64 KiB；关键词限 1–24 个字符，名称按 `\uXXXX` 解码并去除控制字符，非法或超长条目直接丢弃。Host 只向客户端投影 `symbol/name/kind`，不把原始响应或上游错误送出。
- 关键词会发往该第三方接口，但不会进入模型、自选清单或磁盘。目录只用于代码解析：名称与上市状态未与交易所核对，不保证覆盖全部证券，也不构成行情、交易或投资建议。

### 行情现状与可替换接口

**A 股界面默认仍是「未配置行情」。** 插件新增一个**显式选择性开启**的本机适配器 `qt.gtimg.cn`（免密钥、非官方），默认关闭；打开页面「免费源」开关、配置 `marketSource: true` 或设置 `DSH_X_FINANCE_MARKET_SOURCE=1` 才会请求它。它只适合个人本机查看：无 SLA、可能被限流或中断、没有交易所授权，不得对外分发或用于商业展示。Finnhub 工具仍可用，但不会把美股订阅当作 A 股数据源，也不会自动索取或把 `FINNHUB_API_KEY` 发到浏览器。

**全插件只有一个本机免费源开关。** A 股一侧的市场全景、自选详情和底部固定栏都解析同一个 `MarketProvider`，黄金面板也读同一个开关；没有再区分「自选源」「市场源」或「黄金源」。可替换的适配器实现 `name`、`overview()`、`breadth()`、`board(code)`、`quotes(symbols)`，以及可选的 `history(symbol, { adjustment, limit })`、`intraday(symbol)`、`tailScan()` 和 `csi300Funds()`；Host 验证并投影允许字段，不将原始响应、错误或密钥送客户端。没有 `history` 的适配器只让日 K 显示「当前行情源不提供历史日 K」，报价和市场全景照常工作。`freeSource` 配置与 `DSH_X_FINANCE_FREE_SOURCE` 保留为 `marketSource` 的**弃用别名**（等价于强制开启同一个开关），以免既有配置失效。基本面及基于真实来源的分析尚未实现；这些能力未来须单独提供，当前不以 quote 接口虚构它们。

#### 本机免密钥源（可选，非官方）

- 端点固定为 HTTPS `https://qt.gtimg.cn/q=sh600519` 形式，代码由 `SH.600519` 映射为 `sh600519`，`SZ`/`BJ` 同理；固定栏把整条底栏合并成**一次**批量请求（最多 8 个代码，`q=sh600519,sz000001,...`）。拒绝重定向，整个请求含响应体默认 10 秒，响应体上限 512 KiB。
- 响应是 GBK 文本（`v_sh600519="..."`），按 `~` 分隔读取名称、代码、现价、时间、涨跌额与涨跌幅；每个字段重新校验，缺失、越界、代码不匹配或未来时间都会按失败处理。原始响应、错误正文和请求明细不会进入客户端。
- 只投影为 `symbol/status/name/price/changePercent/quotedAt/fetchedAt/marketStatus`。源没有回答的代码是 `unavailable`（价格为空），不会被填成 0、昨收或任何猜测值。`quotedAt` 按交易所时间（UTC+08:00）解释；供应商不提供休市标志，因此 `marketStatus` 固定为 `unknown`，三分钟前的报价由界面标为旧报价。停牌或长期无成交的代码会显示最后一笔价格并因时间过旧被标记，不能被当作实时价。
- 来源名称固定为 `腾讯行情 (unofficial)`，与市场页一致，会在详情页「数据来源」中展示，便于区分授权源。
- 启用方式（选择一种）：
  - 页面「免费源」开关（推荐，写入当前 profile 的 `.dsh-x-finance/market.json`，无需重启）。
  - 当前 profile 的 `cordis.patch.yml` 中按 id 覆盖：`- id: dsh-x-finance`、`name: dsh-x-finance`、`config: { marketSource: true }`；旧的 `freeSource: true` 仍然可用。
  - 启动宿主前设置 `DSH_X_FINANCE_MARKET_SOURCE=1`（旧的 `DSH_X_FINANCE_FREE_SOURCE=1` 仍然可用，适合 headless 组合）。
- 关闭时：不发起任何行情请求，界面保持「未配置行情」，固定栏只显示开启入口。`dsh_x_finance_quote` 工具仍只使用 Finnhub，不会自动改走该源。

客户端 `resources` provider 通过官方 `connection.rpc.call('/api', 'dsh-x-finance.market', { kind: 'quotes', symbols }, signal)` 调用；Host 使用同一 Connection 的 `connection.fetch.register` 精确 POST `/api/dsh-x-finance.market`（不占用 Gateway 的 `/api` 拦截器），验证并回显标准 RPC envelope；官方 shared Connection 在调用精确 route 前强制验证所有者，仅接受 owner principal、确切参数、最多八个不重复的交易所限定代码。原有工具在没有 Connection 的 headless composition 下继续工作。没有自行开放监听端口，也不通过模型调用获取 UI 数据。

**刷新节奏按用途区分**：只有固定栏是准实时视图，它整条底栏合并成一次请求，报价仍在变动时约每 5 秒轮询；报价时间超过三分钟（休市、停牌或源停更）自动降到 60 秒，源关闭时完全停止。详情页按 60 秒更新。隐藏窗口或离线暂停，组件卸载/收起释放订阅并取消在途请求。失败保留资源框架最近成功值并标注旧数据；三分钟前的报价标为旧报价。只有供应商明确提供 closed 才标休市，不用本地工作日规则猜节假日/停牌。此实现是轮询而非推送，不承诺实时或交易所级延迟。

### 市场全景（默认关闭，可在页面开关开启）

股票页顶部增加「自选 / 市场」切换。市场页不依赖自选清单，也不要求先固定股票；所有值都来自一个默认关闭的本机免费源。

- 指数：上证指数、深证成指、创业板指、沪深300、科创50、北证50、中证500、中证800、中证1000、中证全指，以及恒生指数、恒生国企、恒生科技、恒生红筹；显示最新价、涨跌幅、开/高/低/昨收、成交额、行情时间。中证2000 在东方财富接口返回时补充（腾讯/新浪不提供 932000）。A 股指数与四个港股指数都可点开日 K 与量化分析；中证2000 仅显示行情。港股日 K 按港币与香港时间投影，源在成交量位只给成交额，故量能留空而不是把成交额当股数。报价卡上的港股成交额因源未声明币种而留空。
- 行业：31 个申万一级行业与 124 个二级行业；热力图面积按总市值，颜色按涨跌幅，龙头来自板块快照。点击行业读取该板块成交额前 200 只成分股，并展示个股热力图与表格。
- 广度：逐页读取全市场 A 股列表（每页 200，最多 60 页 / 12,000 只），统计上涨/下跌/平盘/停牌、成交额与 11 档涨跌分布，并提供涨幅、跌幅、成交额前列。覆盖不足 90% 时整体失败，而不是用残缺数据计算情绪。
- 情绪：本地可解释模型，不是官方指标。指数动量 20%（仅 A 股指数）、个股扩散 45%、行业扩散 25%、行业动量 10%；广度缺失时按可用因子归一化并标注「部分因子」。公式与权重在页面上可见。
- 页面显示市场状态、行情时间、更新时间和数据来源。状态按上海工作日时段与最新行情时间推断，不识别法定节假日；没有当日行情时只显示「暂无今日行情」，不声称交易中。
- 页面开关：页头提供「免费源」开关；未开启时市场页显示开关与手动配置入口。开启后无需重启宿主即可加载数据，关闭后立即停止市场请求。同一个开关也控制自选页的名称搜索：关闭时搜索框显示开启入口，开启后可原地搜索，无需重启宿主。
- 行情快照分层缓存（指数/行业 60 秒、广度 5 分钟、成分股 2 分钟），只存在宿主内存；窗口隐藏或离线暂停轮询，切换视图取消在途请求；源关闭时不轮询。手动刷新立即重新读取。

启用方式：

- **页面开关（推荐）**：打开股票页的「市场」页签，在「市场数据未开启」卡片或页头打开「免费源」开关。开关状态由宿主写入当前 profile 的 `.dsh-x-finance/market.json`（只含版本与布尔值，不含行情或凭据），不需要改配置或重启宿主；关闭后立即停止市场请求。开关不可用时，卡片仍提供手动配置入口。
- **强制开启（可选，适合 headless 或固定部署）**：当前 profile 的 `cordis.patch.yml` 中按 id 覆盖：

  ```yaml
  - id: dsh-x-finance
    name: dsh-x-finance
    config:
      marketSource: true
  ```

  或启动宿主前设置 `DSH_X_FINANCE_MARKET_SOURCE=1`。强制开启时页面开关显示为已开启且不可关闭；要恢复页面开关，先移除该配置。

### 自选日线研究信号

自选页的「自选量化信号」按现有清单顺序逐只分析，并解释条件和显示来源、日线日期与获取时间。自选只是关注清单，不代表用户持有：退出信号显示为「若持有」。本模块是**尚待样本外验证的研究规则**，不是投资建议、胜率或交易指令；不连接账户、不下单。

- **执行与来源**：点击「分析我的自选」后，才通过已经明确开启的同一个本机免费源逐只请求非官方证券目录和最多 250 根日线。只有目录中交易所加代码精确匹配且分类为股票的才套用规则，ETF、基金、目录无法识别的证券分别标明；目录及 ST 名称未与交易所核对。请求两并发，每只之间设冷却，连续 6 次上游失败即停止，剩余标为未处理；用户可停止，不自动写入自选。行情和证券代码会发往对应免费源，不发送给模型。
- **数据门槛**：至少 120 根有效日线。请求前复权但上游实际返回不复权时不生成方向信号；末日距今超过 7 个自然日或日期异常时暂停方向信号（并不推断是否休市、停牌）。免费源未提供可靠收盘标志，当日最后一根始终显示为「未确认」；历史日线也不声称一定是最近交易日。目录名称出现 ST 标记时暂停买入方向信号，并说明这一判断不等于交易所确认。
- **观察规则**：买入观察 = 最后一根收盘价严格高于此前 20 根最高收盘价且 MA20 严格高于 MA60；退出／风控观察 = 最近两根收盘价分别低于各自当日 MA20。其余显示继续观察，缺失或无效数据不生成确定信号。每条显示相应价格和均线，不推断基本面、公告或可成交性。
- **样本内粗略回放**：用同一规则，收盘出信号、下一根可用日线开盘假设成交；每边佣金和滑点均假设 5bp、卖出税费假设 5bp。买入持有对照从首个可用开盘买入并扣相同买入成本，末尾按收盘估值；未平仓不当成已平仓交易。回放排除未确认的最后日线；不模拟停牌、涨跌停、最低佣金、分红现金、历史 ST 状态、实际成交或复权数据的历史时点偏差。前复权价格不是实际成交价，任何样本内结果均不代表未来或实盘收益。
- **存储**：手动分析结果仅在页面内存，不改变现有浏览器自选清单；关闭页面即清除。不能将离线测试、一次历史回放或免费行情当成实时服务承诺。
- **每日后台自选分析（单独同意）**：自选页的「每日自选分析」明确说明存储和网络边界；只有点击同意后才把当前证券代码镜像到官方 profile 的 `.dsh-x-finance/watch-signal-schedule.json`。镜像清单只含代码，不含自定义别名、账户或持仓；后台结果会保存来源返回的名称和计算指标。后台使用最近一次同步的清单；自选增删后需点击「同步当前自选」。停用需要再次确认，并清除后台镜像和后台结果，不删除浏览器自选。宿主运行且免费源开启时，在上海时间工作日 16:30 后最多尝试一次；周末不运行，但不识别法定节假日。启动时仅尝试补当前工作日，不虚构离线期间的报告。来源日期、未确认和失败数按实际结果显示；免费源关闭时不发起新请求。

### 全市场日线量化（分批与每日任务）

「全市场量化」页在用户手动点击后读取免费源的 A 股目录，按照代码顺序逐股请求前复权日线，而不是先取行情涨幅榜作为候选。界面在页面可见时按冷却时间继续处理后续批次；可停止，离开页面会中止在途请求。每日后台任务需单独明确同意，不会因打开页面自动开启；免费源可能限流或中断，不能保证每天完成全市场。

- 每批最多 150 只、并发最多 2、请求启动间隔至少 500ms，批次上限 90 秒，批间冷却 60 秒；初始证券目录最多 60 页。连续失败或较高失败率会停止，手动扫描进度最多保留 2 小时且只存在宿主 provider 内存。免费源有可能限流、中断或不覆盖全部交易所股票，因此整个源清单处理完也不代表交易所全量已被核对。
- **每日任务（单独同意）**：启用后在宿主运行、免费源开启时按上海工作日 16:45 后尝试分批扫描，可能产生数千次上游请求；启动时若自选后台任务正在运行则先等待，启动后不抢占当前批次。无法识别法定节假日，每天自动尝试最多一次，中断后当天不会自动重复。当前 profile 仅保存最近 20 个报告日期的前 30 候选和覆盖统计，不保存原始日 K；停用任务保留已有报告。没有长期原始日线库或全市场组合回测。
- 同一来源日期、至少 120 根有效日线的样本才计算因子；状态不明、ST、停牌以及因子缺失分别统计。近 20 根日线必须至少 16 根有成交额，缺失不补零。趋势（收盘与 MA20/60）30 分、20/60 日动量分位 30 分、成交额分位 20 分、20 日波动反向分位 20 分；分位只在本次已覆盖的有效同日样本中计算。当前只返回前 30 行，显示分数构成和原始因子。不同批次、数据缺失和复权口径可能改变排名，分数不是收益率或胜率。
- 页面分别显示来源声明总数、识别、请求、日线成功／不足／失败、未请求及排除原因。任何缺口标为部分结果；日线最新日期、实际复权口径和未确认收盘状态均显式显示。来源没有权威交易日历、公告、真实持仓或可成交信息，不产生交易指令。

### 量化分析（新增）

图表下方新增本地面板「量化分析」，只使用已加载的日 K，不请求新数据源，也不把行情发送给模型。指数卡片现在整张可点（包括大号点位），展开日 K 后可直接跳到量化分析。

- **区间统计**：区间收益、年化收益（按自然日复合）、年化波动、最大回撤（含峰谷日期）、夏普（无风险利率 0）、日胜率、最佳/最差单日、ATR(14)、RSI(14)、布林 %B(20,2)、价格相对 MA20/MA60、20/60/120 日动量、52 周高低点与距高点回撤。
- **相关性**：与基准（默认沪深300；基准本身为沪深300时改用上证指数）在重叠交易日上的日收益 Pearson 系数，少于 20 个收益样本时留空。基准按不复权请求；本地面板只用于对照，不是风险模型。
- **月度收益**：按当月首末收盘计算；数据集最后一根仍未收盘时，该月以 `*` 标注。
- **规则回测**：MA5/MA20、MA10/MA60、MACD(12,26,9)、KDJ(9,3,3) 四套固定规则；收盘出信号、**下一交易日开盘**成交，仅做多、满仓、无杠杆；手续费与滑点按每边 bp 计入；最后一笔未平仓交易按最后收盘价卖出并计费。给出策略收益、买入持有、最大回撤、夏普、交易次数、胜率、盈亏比、在场时间、平均每笔、资金曲线与交易明细。
- **口径与限制**：年化波动与夏普按 252 个交易日；ATR/RSI 用 Wilder 平滑；最大回撤按收盘峰谷。买入持有为同期收盘涨幅、未计费用。样本不足 120 根时提示部分指标留空，少于 2 根不计算。所有数字只描述样本内历史，不预测未来，不构成投资建议；日 K 来自本机免费源，非交易所授权行情，最多 1000 根（约 4 年）。

### 尾盘放量下跌扫描（新增）

市场全景页指数区之后新增「尾盘放量下跌扫描」。它只在用户点击「开始扫描」时运行，挂载页面不会自动请求；扫描共用同一个本机免费源开关，关闭时只显示开启入口。面板左侧的「上午盘 / 下午盘」切换要扫的时段：上午盘 = 11:00–11:30 的尾段，下午盘 = 14:30–15:00 的尾段。切换时段只改所选窗口，不会把另一个时段的结果换标签显示；点「开始扫描」才发请求，两个时段各自缓存 90 秒。

- **候选池**：读取已缓存的全部 A 股列表（与广度统计同一份分页快照），保留当日跌幅 ≥ 0.5%、成交额 ≥ 3,000 万元、非停牌、非 ST/退市/新股简称的股票；再用腾讯批量报价读取量比，按「跌幅 + 量比 + 成交额」排序取前 32 只。全市场覆盖不足 90% 时整次扫描失败，不用残缺列表下结论。
- **尾盘确认**：读取 1 分钟分时，计算所选时段的尾盘涨跌、尾盘成交量、尾盘量比和尾盘成交占比；只有尾盘量比 ≥ 1.3 且尾盘跌幅 ≥ 0.3% 才进入结果。尾盘量比的分母是尾段之前的完整基线块：下午盘用 10:00–14:30 各 30 分钟成交量中位数；上午盘只有 10:00–11:00 可用，用 6 个 10 分钟块折算成 30 分钟口径（×3），因此两个时段的量比可以直接对照。尾盘窗口未结束或分时点数不足时标记为不完整（上午盘在 11:30 之后即算结束，不要求下午的分时），不把盘中数据当成已收盘。
- **分时来源**：优先腾讯分时；该接口在持续请求后可能返回 HTTP 501 挑战页，此时自动改用新浪 1 分钟 K 线 JSONP（同为免密钥、非官方、本机用途），不重试被拒绝的请求，也不绕过验证。两个来源都失败时该股票计入 `failedIntraday`，结果标记不完整。
- **连续放量下跌**：对尾盘确认的股票读取最多 250 根前复权日 K，计算日量比（5 日/20 日）、连续下跌天数、**连续放量下跌天数**、放量下跌分布、RSI(14)、ATR(14)、MA20/60 偏离、20/60 日动量、52 周回撤与区间收益/波动/最大回撤。连续放量下跌同时给出两种口径并取较大值：①连续下跌且成交量逐日放大；②连续下跌且成交量 ≥ 前 5 日均量 1.2 倍。页面可勾选「只看连续放量下跌（≥2 日）」。
- **评分**：尾盘量比 30 + 尾盘跌幅 25 + 当日跌幅 15 + 日量比 15 + 连续天数 15，满分 100；缺失项按 0 计。评分只描述本次样本，不是预期收益。Host 会重新校验所有指标并重算评分，不信任适配器传入的分数。
- **量化分析**：表格展示当日/尾盘涨跌、尾盘量比、日量比、连续天数、RSI、距 MA20 与评分；点击股票或「查看量化」进入详情页，可在日 K 下方的完整量化面板查看收益、波动、回撤、ATR、布林、相关性、月度收益与规则回测。扫描结果只在内存中缓存约 90 秒，不写入自选、会话或磁盘，也不上传模型。
- **时段口径**：Host 的请求带 `window: 'morning' | 'afternoon'`，不带时按下午盘处理，旧客户端行为不变。结果同时返回 `window`/`windowStart`/`windowEnd`，Host 会校验每一行尾段的起止时间与窗口一致，不一致的适配器结果直接判定无效，不会在 UI 里改名展示。两个时段的缓存键分开（`tail-scan:morning` / `tail-scan:afternoon`），不会串用。
- **口径与限制**：分时与日线均来自非交易所授权的本机免费源，无 SLA，可能延迟、限流或中断；不是 Level-2、资金流、新闻或交易指令，不构成投资建议。周末或节假日运行会显示「最近交易日（非今日）」。日 K 最多 1,000 根，扫描固定取 250 根；不识别法定节假日、停牌成交或盘后固定价格交易。真实桌面像素与长期限流行为仍需在目标环境单独验收。

### 热点题材筛选（新增）

股票页新增「热点」tab：一次手动运行，把全市场按 35 条内置策略打分排序。它和尾盘扫描一样**不会自动运行**，共用同一个本机免费源开关；关闭时不发任何请求。

- **两层策略，口径写在结果里。** 快照层（19 条）对全市场运行，数据来自腾讯排行接口：涨幅、量比、换手率、成交额、主力净流入、振幅、涨速、5/10/20 日涨幅、涨停、距涨停≤2%。历史层（16 条）需要日 K，只对快照得分最高的 120 只复核：布林突破、MACD 金叉/多头、均线多头、站上 20 日线、放量突破、20/60 日新高、RSI、连续放量、缩量回踩、放量阳线、5 日线上穿 10 日、连板/首板。结果里的「历史复核 120/120」就是这一层的真实覆盖，不含糊。
- **命中不是「有一条规则碰到」。** 至少要命中一条权重 ≥ 2 的策略；权重 1 的规则只加分和打标签。否则「主力净流入>0」这种宽条件会把大半个市场都算成命中，标题数字就没有意义。
- **评分是本轮相对值。** 评分 = 命中权重之和 ÷ 本轮最高权重 × 100，第一名恒为 100；它只用于本次排序，不是收益率、概率或评级。列表最多展示 60 只，标题仍报真实命中总数。
- **范围可按申万二级行业收窄。** 顶部行业标签来自市场全景已缓存的申万二级行业（免费源不提供概念板块，界面不冒充）；点一个行业只扫它的成分股。
- **只读 + 显式写入。** 点股票名打开**独立的临时详情页**（不显示左侧自选栏、不切换页签，顶部有「返回上一页」），不写入自选；只有「+」或「批量加自选」才写入清单，且批量加入不改当前选中股票。
- 实测（2026-10-25，直接调用 provider）：覆盖 5,577 只、快照扫描 5,572 只、历史复核 120 只、0 失败、**2.5 秒**、命中 1,198 只；榜首为利亚德（+20%，29 个标签）。这是本地运行结果，不是投资建议。

### 涨停接力概率（新增）

股票页新增「预测」tab。它回答一个问题：**今天涨停或准涨停的这些股票，下一个交易日继续封板的概率有多大，历史上同类样本后来赚了多少。** 它不给目标价，也不给「买入」结论——样本外的接力是亏钱的，面板把这件事直接写在最上面。

- **只算概率，不算收益。** 训练集里收益率模型的样本外横截面 IC 是 **-0.038**（月度滚动重拟合），而晋级概率的 AUC 是 **0.680**、Brier **0.137**（基准晋级率 18.9%）。所以插件只输出概率与「同组历史期望」，不输出模型预测收益：一个 IC 为负的点估计只会制造假精确。
- **概率之外的三个数。** 每行给出：模型概率、同组基准（同一连板档的历史晋级率）、偏差（概率减基准，单位个百分点）；以及该档的历史接力期望、胜率和样本量。看起来「概率最高」的票，开盘溢价也最高，按概率买反而更亏——面板不回避这个结论。
- **规律是测出来的，不是编的。** 全样本按连板高度分档（n=14,258）：

  | 档位 | 样本 | 次日晋级率 | 次日开盘溢价 | 接力期望 | 胜率 |
  | --- | --- | --- | --- | --- | --- |
  | 未封板（冲板失败） | 1,565 | 6.3% | +2.23% | -3.41% | 32.8% |
  | 首板 | 9,858 | 17.8% | +2.15% | -0.36% | 43.9% |
  | 2 板 | 1,758 | 32.7% | +3.18% | -0.69% | 43.5% |
  | 3 板 | 574 | 44.1% | +3.72% | -0.99% | 45.8% |
  | 4 板及以上 | 503 | 49.7% | +4.06% | +0.19% | 52.5% |

  规律很清楚：**连板越高，晋级概率越高、开盘溢价也越高，而接力期望在扣费后几乎全为负。** 概率与收益是两件事。
- **样本外结果（2025-10-23 至 2026-10-23，243 个交易日、5,682 条样本）**：按「概率 − 同组基准」排序取前 3 只，次日开盘买入、T+2 收盘卖出、扣 0.2% 往返成本，平均 **-1.84%/笔**，累计 -99.2%，最大回撤 -99.3%。按绝对概率排序更差（前 3 只 -1.52%/笔）。情绪高位档的样本外期望为 +0.69%（n=1,254），但全样本同档为 -1.60%——这个「择时优势」不稳定，不能当成结论。
- **特征与训练口径。** 21 个特征全部从日 K 与全市场横截面算出来：连板高度、封板/距涨停、1/5/20 日涨幅、跳空、振幅、收盘位置、量比、成交额放大、偏离 5/20 日线、近 5 日炸板数、20 日涨停次数、距 20 日高点、一字板，以及三个情绪分位与一个交互项。市场级特征先按训练期分位点（21 个 knot）转成 0–100 分位，避免 2024-09-30 那种「64% 的股票涨超 9%」的单日极端值主导整条系数；标准化输入在 ±5 个标准差处截断。训练与服务共用 `predict-features.ts` 里的同一份特征函数，不存在训练/服务漂移。
- **滚动重拟合，不偷看未来。** 样本外检验按月重拟合：预测某个月时，只用该月之前的数据；情绪分位点的 knot 也只用样本外区间之前的数据。面板展示的系数用全样本拟合，并明确标注 `trainedThrough` 与模型「已多少天未重拟合」。
- **样本与研究脚本。** 研究样本为按代码等距抽取的 1,471 只沪深股票、620 个交易日（2024-03-29 起），不含北交所、ST 与新股；不含已退市股票，存在生存者偏差，实测收益偏乐观。重跑：

  ```sh
  node scripts/finance-research.mjs fetch   # 拉取并缓存日 K 到 .research/（已 gitignore）
  node scripts/finance-research.mjs fit     # 滚动检验并生成 src/predict-model.ts
  node scripts/finance-research.mjs scan    # 用真实 Host provider 跑一遍今日榜单
  ```

  `src/predict-model.ts` 是生成文件，文件头写明不要手改；系数、分位点、基准表与样本外指标都在里面。
- **运行时口径。** 运行一次 = 一次全市场排行快照（约 5,577 只）+ 最多 90 只候选的 80 根日 K（并发 4）；宿主缓存 2 分钟，重复点击不重复抓取。盘中运行时最后一根日 K 未收盘，结果标「盘中（收盘前会变）」；候选与情绪都用当时的值。次日一字锁板在开盘买不到，回测里已剔除。
- **实测（2026-10-27 13:13，直接调用 provider）**：覆盖 5,577 只、候选 50 只、评分 50 只、0 失败、**1.3 秒**；情绪档位「冷清」（强势股占比 1.1%、上涨占比 19.3%、历史分位 12）；榜首多伦科技（4 板，晋级概率 73.4%，同组基准 49.7%）。这是本地运行结果，不是投资建议。
- **边界。** 只读、不写自选、不下单；数据来自腾讯公开行情（非官方、无 SLA）；概率是历史条件频率，任何单日都可能证伪；A 股 T+1，当日买入不能卖出，所以「接力」口径是次日开盘买入、T+2 收盘卖出。

## 黄金面板（新增）

股票页新增第三个页签「黄金」。它与自选、市场共用同一个本机免费源开关：关闭时不发任何请求，只显示开关；开启后无需重启宿主。黄金数据来自新浪财经公开接口（`hq.sinajs.cn`、`stock2.finance.sina.com.cn`），与腾讯 A 股源一样是**非官方、无 SLA、不可再分发**的本机个人用途源。

- **报价矩阵**：伦敦金 XAU/USD、纽约期金 GC、纽约白银 SI、沪金99、黄金延期 Au(T+D)、离岸人民币 USD/CNH，合并为**一次**批量请求。
- **每个标的**给出：现价、涨跌额、涨跌幅、开/高/低/昨收、振幅、行情时间。涨跌额与百分比优先用源字段，否则由昨收与现价计算；任一项缺失就留空，不补零。
- **折算与价差**：伦敦金（美元/盎司）× 离岸人民币 ÷ 31.1034768 = 元/克，再与沪金99 相减得到沪伦价差与溢价率；金银比 = XAU/SI。页面明确写出公式，并声明这只是口径对照，不代表可套利。
- **区间变化**：新浪全球期货日线（JSONP，解析后只保留最近 260 根）计算 5 日/20 日/60 日/年初至今涨跌、52 周高低点与距高点回撤。单条日线失败时该行留空并标注「部分日线暂不可用」，不用快照价格倒推。
- **单位与时区**：美元/盎司与元/克按源原样展示，不推断源未声明的币种；时间按北京时间解释，非法、未来或过旧的时间戳置空。黄金接近 24 小时交易，与 A 股 4 小时会话不能直接对齐，页面注明。
- **安全边界**：固定 HTTPS 主机、拒绝重定向、10 秒超时、响应上限（快照 64 KiB、日线 4 MiB）、GBK 解码、逐字段校验；原始响应、上游错误与请求明细不出宿主。宿主内快照缓存 15 秒、日线 10 分钟。
- **不抓新闻，不做事件归因。** 插件只给可核对的价格与区间数字；宏观事件与热点请在对话里提问，由模型联网检索并给出来源链接。

## 日 K 图表工作台（第一版）

图表采用官方 Lightweight Charts 5.2.1，单 chart 的 K 线/成交量/MACD/KDJ/Z-Score 五个窗格共享时间轴，%B 窗格按需打开；MA5/10/20/50/250、KDJ、BOLL 通道、%B、Z-Score 可单独开关，DIF/DEA 可显隐。MA5/10/20 默认开启；MA50、MA250（季线/年线）与 %B 默认关闭，需要时在工具栏勾选。均线按**已加载的全部日 K** 计算：不足该周期的根数时整条线留空并给出说明，不拿已有数据硬凑；在周 K/月 K/年 K 视图下，长周期均线的周期单位随之改变，页面会提示切回日 K 才是日线口径。周 K、月 K、年 K 由已加载日 K 在本地合并，不另请求、不补缺失成交量；未结束的周期标为未收盘。拖动和平移、缩放、十字线、点击锁定读数、Esc 解锁、获焦后方向键/Home/End 逐根查看、回到最新、MACD 副图放大与参数显式应用均可用。提供分页数据表作为 Canvas 的文本替代。跟随 DSH 中英文和主题，颜色固定红涨绿跌，不随语言变化。

免费源开启后，工作台默认读取同一来源的日 K（`{ kind: 'history', symbol, adjustment, limit }`，最多 1000 根）。复权请求为前复权、不复权或后复权；若上游对某证券不返回复权序列（例如科创板、指数），界面按实际返回的 `day` 标成不复权，不把未复权数据说成前复权。成交量单位不按代码猜：用成交额与收盘价核对，接近收盘价视为股，接近 100 倍收盘价视为手并折算为股，对不上则整段成交量留空。指数成交量是交易所合计口径，轴上标「指数口径」，不当成股数。源没有收盘标志：日期等于上海当天的最后一根标为未收盘，更早的根标为已收盘。日 K 只在打开详情或指数图时请求，关闭免费源后不再请求；宿主内存缓存约 60 秒，不写入自选或磁盘。

用户仍可显式打开 **DEMO:SYNTH 合成数据**，或导入自己有权使用的日 K JSON。这两种数据只进入此页面内存，切股、离开/刷新或切换 profile 后清除；不会上传服务器/模型、写入自选、缓存原始文件，或填充底栏的实时报价。图表偏好和所选复权方式只按宿主 profile 的 scope 保存到本地。本地导入的来源标签是文件声明，不能据此验证真实性；无基本面/财务数据则继续为空。

导入格式下载按钮提供完整合成示例。上限 2 MiB/5,000 根；schemaVersion=1，必须明确 symbol、currency、exchangeTimezone、interval="1d"、adjustment、adjustmentRevision、datasetRevision、pricePrecision、volumeUnit="shares"、volumeAdjustment、amountAdjustment、source。bars 必须按 sessionDate 升序唯一，含 OHLC、volume（缺失用 null）、isFinal；本地导入支持价格绝对值不超过 1e12，量额不超过 Number.MAX_SAFE_INTEGER，以保证计算和绘图数值安全；这不是金融理论边界。具体字段及校验见 `src/chart-data.ts`。日线使用交易所会话日期而非浏览器本地时间，价格未复权时必须正数；已复权价格可以为非正有限值，但必须声明方法且满足 OHLC 顺序，不擅自截零。成交量及成交额口径分别声明，缺失量不补零。文件 symbol 必须匹配当前股票；无已选股票时可独立浏览其他合格文件。

指标算法版本 `dsh-independent-sma-ema-v1`（以源码导出为准）：每条 EMA 独立以其周期 SMA 播种；DIF=快 EMA−慢 EMA，DEA 为 DIF 的 EMA；默认 12/26/9，柱=2×(DIF−DEA)，可显式改 ×1。KDJ 默认 9/3/3：RSV 用 N 根最高最低，K/D 从 50 按 1/3 平滑，J=3K−2D；最高价等于最低价时 RSV 记 50。BOLL 默认 20/2：中轨即 20 根收盘均值（与 MA20 同一函数，不是第二套实现），上下轨为中轨 ± 2 倍样本标准差（n−1）；%B=(收盘−下轨)/(上轨−下轨)，Z=(收盘−中轨)/标准差，标准差为 0 时两者留空而不是记 0.5/0；Z 副图只在 0 与 ±2σ 处画水平参考线，这是全图唯一的人为阈值。完整预热前为缺失值，缺口重置连续预热；不按可见窗口重算。这个种子规则与 TA-Lib MACD 内部对齐播种不同，不能宣称逐点一致。量化回放只按当前周期的收盘价记录金叉到下一次死叉的涨跌，不含手续费、滑点、仓位或下单，不是预测。修订/末根替换与历史补齐采用最多 5,000 根的有界全量确定性重算，渲染适配器可对新增/末根使用 update，保留历史阅读锚点；目前无历史 provider 分页取数。

Apache-2.0 的 Lightweight Charts 及 MIT 的 fancy-canvas 许可和 NOTICE 随 `licenses/` 打包；保留 TradingView logo 和可见归属链接。没有使用 Advanced Charts，也不包含任何行情授权。分时来自东方财富公开走势（与日 K 的腾讯源分开），横轴是北京时间且午休不占位置，左轴是价格，右轴是较昨收涨跌幅，成交量按手显示。它不是 1 分钟 K，也不会在没有分时时用日 K 补一条线。当前没有对数坐标、分钟 K、交易功能或真实基本面分析。

### 分时的重试与回退

东财 `push2` 分时接口在忙或限流时不是返回错误码，而是**直接断开连接**（`Empty reply from server`，实测约三到六成请求会这样），原先一次失败就整块显示「分时获取失败」，只能手点重试。现在按下面的顺序兜底：

- **单源重试**：同一次请求失败就立即再试一次（断开是瞬时的，重试几乎不增加等待；单次预算 5 秒）。
- **换源**：东财连续失败后改用腾讯的 1 分钟分时（与尾盘扫描同一个接口）。腾讯只给累计成交量/成交额，所以每分钟成交量取相邻累计值之差，均价用「累计成交额 ÷（累计手数 × 100）」还原；价格、累计量、均价与东财逐分钟核对一致（同一天实测 95 个共同分钟，价格与累计量完全相同，均价差在 0.0005 以内）。回退时页面明确标注来源为「腾讯分时」，不会把腾讯的数据说成东财。
- **冷却**：刚失败的源在一分钟内不再请求，避免限流期间每次轮询都白等两次超时；另一个源在此期间保持出图。
- **区分「取不到」与「没有」**：两个源都是传输失败时报「分时获取失败」；只要有一个源明确回答「这只股票没有分时」，才报「暂无分时」。
- **前端不再闪烁**：浏览器端在一次失败后最多再试 3 次（间隔 0.7/1.4 秒）；已经有线在图上时，刷新失败不会清空图，而是保留上一次抓到的分时并在下方标注抓取时间与重试按钮。

## TypeScript development

Host sources live in `src/` with entry `src/index.ts`; browser sources are in `src/client/`, and package tests are `test/*.test.ts`. The shared builder emits host JavaScript and declarations into `lib/` and bundles `lib/client.js`. `main` and the root export use `./lib/index.js`; built artifacts ship with the package and remain tracked in this repository.

```sh
pnpm --filter dsh-x-finance run typecheck
pnpm --filter dsh-x-finance run build
pnpm --filter dsh-x-finance test
```

The root `pnpm test` builds every package before running source unit tests and built-entry integration tests.
