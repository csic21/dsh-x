# dsh-x-ui

把 DeepSeek Harness 的 Web 界面换成 liquid glass 质感：半透明面板、会流动的底色，以及浮层上真正的模糊。

## 它怎么做到的

不是替换主题样式表，也不改内核。两层叠在官方主题之上，随时可以完整摘掉：

1. **token 覆盖层**：通过官方 `ctx.theme.overrideTokens(source, tokens)` 叠一层 alias token。每个值都是 `var(--dxu-*, <官方默认值>)`，所以颜色仍然来自官方 `--dsw-static-*` 原始色板，只有透明度和模糊是插件的。
2. **材质样式表**：插件自己的一个 `<style>` 节点，定义 `--dxu-*` 变量（按浅色/深色、按浓度），并给少数需要真模糊的面板加 `backdrop-filter`。

选择落在官方 profile 目录下的 `.dsh-x-ui/appearance.json`，不写官方 `sessions/`，也不建第二个 home。

## 只改表面，不改文字

token 层只覆盖"面"：背景、浮层、输入框、菜单、遮罩、代码块底色、气泡、工具提示。**文字、状态色、品牌色、语法高亮一律不动** —— 半透明的文字会在底色一动就失去对比度。

## 三个可调项

| 项 | 作用 |
| --- | --- |
| 启用玻璃材质 | 总开关。关掉立刻回到官方样子，选择保留。 |
| 材质浓度 | `清透` / `标准` / `厚实`：面板透明度与模糊半径一起变。 |
| 流动底色 | 面板后面的四团彩色渐变。关掉后只剩半透明，玻璃会显得发灰。 |
| 高光边缘 | 输入框顶部的高光与描边，让面板像玻璃而不是灰片。 |

全部在 **Settings → General → 玻璃界面** 里，写盘后立即生效，不用重启。

## 其它插件怎么接入

本仓库其余插件（Code、Finance、Browser、Pet）的界面也会跟着变成玻璃材质。它们各自读本包发布的两个变量，并用自己的原色作为回退：

| 变量 | 含义 |
| --- | --- |
| `--dxu-blur-panel` | 浮在对话之上的 chrome（标题栏、工具栏、底栏、气泡、弹窗）用的模糊。回退值 `none`。 |
| `--dxu-pane` | 阅读正文的内容面板用的近乎不透明底色（94%）。回退值是该插件原来的底色。 |

两条原则：

- **chrome 透，内容实**。浮动在对话上方的条状 chrome 才做模糊；代码阅读器、行情表这类阅读面保持近乎不透明——把长文本放在流动底色上会让可读性变差，而且整片模糊每帧都要重新合成，看不出差别却要付代价。
- **模糊不能落在有 `position: fixed` 后代的元素上**。`backdrop-filter` 会让宿主成为包含块，浮动菜单和遮罩会因此错位。Code 的右键菜单就挂在页面根内，所以页面根不做模糊，只给标题栏和工具栏做。

没装本包时，这两个变量不存在，各插件的规则全部退化成原来的样子，不会出现半透明却没模糊的破面。

## 锚点用的是什么

只使用宿主自己的 `data-*` 钩子和文档化的 token 契约：

- `body[data-ds-dark-theme]`、`html[data-platform]` —— 官方主题与平台
- `[data-composer-card]`、`[data-menu-material]` —— 官方输入框与菜单材质
- `[role='dialog']`、`[data-shell-overlay]`、`[data-shell-bottom]`

**不选择任何 `JZLxKW_card` 这类构建哈希类名**：它们在宿主每次重建后都会变，插件会在下一次内核升级时静默失效。测试里有一条断言专门守这个约束。

## 无障碍

- `prefers-reduced-transparency: reduce` 时自动回到官方不透明配色，并关掉所有模糊。
- `prefers-reduced-motion: reduce` 时去掉底色的淡入过渡。
- 设置行的开关用 `role="switch"` + `aria-checked`，分段控件用 `aria-pressed`，都带键盘焦点环。

## macOS 上的特殊处理

Desktop 主窗口本身已经是原生 vibrancy（`vibrancy: "sidebar"`），系统已经在窗口后面做了一次模糊。所以底色层在 `data-platform=darwin` 下会降到 72% 不透明度，让系统材质透上来，而不是把窗口糊成一块平板。

## 已知限制

- 这是**视觉层**，不改变任何布局、命中区域或交互。官方组件的间距、圆角、焦点环保持原样。
- 浓度只影响本插件定义的 `--dxu-*` 与透明度，不会重写官方 `--dsw-radius-*`、字体、字号。
- 官方如果重命名 token 或 `data-*` 钩子，降级方式是"少一层玻璃"而不是渲染失败：覆盖层里的每个值都带官方默认值作为 fallback。
- 打包应用与真实浏览器下的观感不在本仓库的测试范围内；仓库内验证的是 token 层注册、样式节点生命周期、存储与路由校验。
