# dsh-x-pet

在 DeepSeek Harness 窗口里放一只**与 Codex 完全同规格的桌宠**：同一套精灵表、同一套动画时序、同一个本机桌宠目录。

## 兼容到什么程度

这个插件不是"仿制"Codex 桌宠，而是直接使用 Codex 的桌宠规格：

| 项目 | Codex | 本插件 |
| --- | --- | --- |
| 精灵表 | PNG / WebP，1536 宽，192×208 一格，透明底 | 相同 |
| 版本 | v1 = 1536×1872（9 行），v2 = 1536×2288（11 行） | 相同，按图片高度自动判断 |
| 本机桌宠目录 | `${CODEX_HOME:-~/.codex}/pets/<名字>/` | 相同，只读 |
| 桌宠清单 | `pet.json`：`id`、`displayName`、`description`、`spritesheetPath` | 相同 |
| 动画行 | idle / running-right / running-left / waving / jumping / failed / waiting / running / review | 相同 |
| 每行帧数与时长 | 见下表 | 相同，逐帧一致 |
| 空闲呼吸 | idle 帧时长 ×6 循环 | 相同 |
| 一次性动作 | 连播 3 遍后落回慢速 idle | 相同 |
| 视线跟随 | v2 的第 9、10 行共 16 个方向，每 22.5° | 相同 |

逐帧时长（毫秒）：

| 行 | 帧数 | 时长 |
| --- | --- | --- |
| idle | 6 | 280, 110, 110, 140, 140, 320 |
| running-right / running-left | 8 | 120 ×7, 220 |
| waving | 4 | 140 ×3, 280 |
| jumping | 5 | 140 ×4, 280 |
| failed | 8 | 140 ×7, 240 |
| waiting | 6 | 150 ×5, 260 |
| running | 6 | 120 ×5, 220 |
| review | 6 | 150 ×5, 280 |

所以：在 Codex 里做出来的桌宠（`hatch-pet` 等工具生成的 `~/.codex/pets/<名字>/`），放进本插件的窗口里就是同一只、同一套动作。

## 行为

- **浮在窗口上**：桌宠挂在 `shell.overlay`（整帧浮层），不占用对话区、侧栏或底栏的位置。
- **跟随会话状态**：当前会话在跑 → `running`；在等审批或提问 → `waiting`；一轮结束还没看 → `review`；其余 → `idle`。
- **指针悬停**：换成 `jumping`（与 Codex 一致）。
- **指针跟随视线**：v2 精灵表在空闲时用第 9、10 行的 16 个方向看向指针。
- **可拖动**：按住拖动才换位置，松手不会顺带打开选择器；轻点才打开选择器。位置按当前 profile 保存。
- **会说话**：气泡第一行是会话标题，第二行是这轮在用什么工具和已经跑了多久（`正在用 bash · 0:42`）；多会话并发时右侧有 `+N`，点一下轮到下一个；一轮结束打 ✓。点气泡右侧的 × 只收起这条提示，不影响会话，下一轮会再出现。
- **独立窗口**：悬停后点「独立窗口」把宠物放到自己的窗口里（`/api/dsh-x-pet/frame`）。浏览器里直接可用；桌面端需要壳层开一个透明置顶窗口，改法见 [docs/dev/desktop-pet-window.md](../../docs/dev/desktop-pet-window.md)。
- **完成提醒**：设置里可以打开系统通知，窗口在后台时用通知告诉你这轮结束。
- **可关闭**：点开选择器可以切换桌宠或隐藏。
- **设置页**：账户菜单里的「设置」增加「桌宠」一页，里面有显示开关和角色格子。Codex / ChatGPT 自带的角色（Codex、Dewey、Fireball 等）从本机已安装的应用里只读出来，不打包进这个插件。

## 使用

- 悬停桌宠出现按钮：**选择桌宠** 打开选择器，**隐藏桌宠** 把它关掉。
- 选择器列出内置桌宠和 `~/.codex/pets` 里的本机桌宠（缩略图就是它自己的 idle 第一帧）。
- 模型也可以用 `dsh_x_pet` 工具：`list` 看有哪些桌宠，`select` 换一只，`hide` 收起，`move` 调位置。这个工具只改外观，不碰文件、审批或会话。

## 边界

- 只读 `${CODEX_HOME:-~/.codex}/pets`。插件不写 Codex 的目录，也不动官方的 `sessions/`。
- 选择与位置写在当前 profile 目录下的 `.dsh-x-pet/pet.json`（官方位置，非独立 home）。
- 精灵表必须真的是 1536×1872 或 1536×2288；不合规格的文件会被跳过，不会被拉伸显示。
- `pet.json` 只能指向自己目录里的普通文件名；清单 id 与目录名不一致的桌宠不加载。
- 单张精灵表最大 8 MiB。
- 内置桌宠是本仓库自己程序化生成的原创美术，不包含任何第三方素材；Codex 自带的桌宠仍需由用户自己的 Codex 提供。

## 验证

在本目录运行 `pnpm test`，不需要网络或 Codex。覆盖：帧表与逐帧时长、idle 慢速与一次性动作的回退、reduced motion、视线方向换算、精灵表尺寸校验、本机桌宠发现与坏文件跳过、选择与位置的持久化、路由信封校验，以及已构建客户端在 JSDOM 中的挂载与状态映射。

本仓库不验证打包后的 Desktop 应用表现：Electron 行为需要在打包环境单独确认。
